# 🎬 Thư Mục Chứa Video & Hoạt Ảnh (Animation Assets)

Nơi đây dùng để lưu trữ các tệp video hoạt họa, animation clips, hoặc hình ảnh hiệu ứng của game Ma Sói:

### Các định dạng khuyến nghị:
- **Video:** `.mp4`, `.webm` (ví dụ: video mở mắt, video quả cầu pha lê vỡ, video sói cắn, video thiên thần hóa thân...)
- **Animation Lottie (nếu dùng):** `.json`
- **Ảnh động / Hiệu ứng:** `.gif`, `.webp` (trong suốt / transparent background)
- **Âm thanh hiệu ứng:** `.mp3`, `.wav`, `.ogg`

---
### Cách sử dụng trong code React Native / Web:
```javascript
// Ví dụ nạp video hoặc hoạt ảnh:
import SeerCrystalVideo from '../assets/animations/seer_crystal.mp4';
```
